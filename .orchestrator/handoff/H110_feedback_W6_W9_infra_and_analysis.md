## Assumptions / limitations

- The committed sample panel (`data/samples/panels/daily_rollup_panel_v1_sample.csv`) is **synthetic** and intended for deterministic `--sample` runs only.
- `src/analysis/str_empirical_tests.py` reports p-values using a **normal approximation** (stdlib-only; no SciPy/Statsmodels). This is acceptable for pipeline validation but should be replaced/augmented for publication-grade inference.
- `scripts/make_processed_manifest.py` records `git_sha` via `git rev-parse HEAD` (it does not attempt to encode “dirty tree” state).
- Task dependency wiring (adding `dependencies: ["T096"]` to tasks that emit processed manifests) is a **Planner** change; not updated here.

## Downstream impact

- W1/W2/W9 tasks that emit `data/processed_manifest/*` should standardize on `python scripts/make_processed_manifest.py ... -- <command...>`.
- W6 analysis scripts can now be required to include `--sample` mode and commit sample outputs to make CI deterministic.
