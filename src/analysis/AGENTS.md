# src/analysis/AGENTS.md — Analysis Rules

Analysis must be reproducible and must not silently fetch new data.

## MUST

- No network calls. Consume only local `data/processed/` artifacts.
- Deterministic outputs: fixed seeds where relevant.
- Every figure/table must be generated by code.
- Record analysis parameters and seed in report metadata when producing task outputs.
- Keep analysis functions composable (input data -> output metrics/artifacts).

## Outputs

- Figures saved under `reports/figures/` with stable names.
- Any model outputs saved under `reports/tables/` or `reports/models/`.

## SHOULD

- Provide a single entrypoint (script/function) for reproducing each analysis artifact set.
- Keep plotting logic optional/lightweight relative to core metric computation.

## Documentation

Each analysis script/notebook must include:
- inputs it reads
- outputs it writes
- how to run

## DO NOT

- Do not rely on notebook session state as the sole source of truth.
- Do not write analysis artifacts outside `reports/` unless explicitly task-required.
